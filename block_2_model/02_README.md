# Комплект по Блоку 2 — Проектирование аналитического решения

## Состав
- `02_model.md` — архитектура, ER-модель, зерно таблиц, правила ключевых бизнес-сценариев.
- `02_model_erd.mmd` — ER-диаграмма Mermaid.
- `02_model_ddl_postgresql.sql` — целевой DDL PostgreSQL с типами, ключами и индексами.
- `02_model_metrics.md` — матрица метрик (более восьми), предлагаемое определение OTIF и план разведения «94% против 71%».
- `02_model_data_quality.md` — наблюдаемые проверки качества, SQL для воспроизводимости и обработка дефектов.
- `02.5_transformations.md` — правила трансформации и нерешённые допущения.

## Проверенные артефакты
- `severtrade_model.db` — SQLite-прототип, построенный из исходного датасета.
- `02.1_model_build.sql` — SQL сборки SQLite-прототипа.
- `02.1_model_validation_ru.md` — отдельный отчёт валидации прототипа.

## Важное ограничение
SQLite-прототип и целевой PostgreSQL DDL — разные артефакты: первый нужен для воспроизводимой проверки данных, второй — проект целевой схемы. DDL не выдаётся за проверенный PostgreSQL migration run. Неопределённые правила перечислены в основном документе.
